# 決策紀錄

## 2026-10-22 初版版型

- **只做電腦版**（使用者指定）：`viewport` 固定 1280、`body` 最小寬 1100px，不寫手機版樣式。
- **共用導覽用 JS 插入，不每頁複製**：文章清單只寫在 `nav-data.js`，用 `<script src>` 載入而不是 fetch，所以 file:// 雙擊也能用。代價是不開 JS 時看不到側欄（內文仍完整）。
- **「試試看」用 iframe srcdoc + sandbox="allow-scripts"**，不外連 CodePen：不離開網站、沒有外部依賴。
- **語法高亮用 Prism 1.29.0（cdnjs）**，配色自己寫在 site.css，淺深色都用深底程式碼區塊。
- **閱讀進度存 localStorage**：只存在該台電腦的瀏覽器，換電腦會歸零；頁面上有明講。
- **比喻卡內的短程式碼不顯示複製按鈕**：按鈕會蓋住只有一行的程式碼。
- **第 4 個實戰範例先定為番茄鐘**（另一個選項是小測驗），使用者尚未指定，之後可換。
- **基礎第 1 章練習改成貼上完整範本**：只寫一行 `<p>` 而沒有 `<meta charset>` 時，中文在本機開啟可能變亂碼。

## 2026-10-22 第 2 章

- **`.cards` 只有兩張時自動改兩欄**（`:has()` 判斷），文章作者不需要另外加 class。
- **流程圖（`.flow`）格子內不放快捷鍵**：一長串 `<kbd>` 在窄格子裡會斷成好幾行，改放在流程下方的段落。
- **第 2 章起正式開始「我的自我介紹頁」**：資料夾 `my-first-web/index.html`，用 VS Code 的 `!` 產生骨架；第 1 章的 `hello.html` 只是暖身。

## 2026-10-22 第 3 章

- **程式碼字型關掉連字**：JetBrains Mono 預設會把 `<!--`、`-->`、`=>` 畫成箭頭，新手照著打會打錯，所以 `code`、`pre`、`kbd`、試試看編輯區一律關掉 `liga` 與 `calt`。
- **試試看裡不放圖片**：預覽 iframe 載不到讀者電腦裡的圖檔，放了只會產生失敗的請求；圖片改在練習時用自己的 `images/me.jpg` 試。
- **表單的「必填」提醒改到練習裡試**：預覽 iframe 只有 `allow-scripts`，Chrome 會先擋下送出、不跑必填檢查，所以文章明講預覽區按送出沒反應，加分題再用自己的檔案試 `required`。不為此開 `allow-forms`：開了以後送出會讓預覽區跳到空白頁，反而更難懂。
- **預覽區點連結會在小框裡開啟外部網站**：維持現狀，文章說明改一個字或按「重設」就能回來。
- **AI 產生的頁面另存新檔**（例如 `ai-test.html`），不貼進 `index.html`，避免蓋掉讀者自己寫的自我介紹頁。

## 2026-10-22 第 4 章

- **CSS 只教 `px`**，不教 `em`／`rem`／`%`。例外是圖片的 `max-width: 100%` 和圓形大頭照的 `border-radius: 50%`，文中標明「照抄即可」。
- **字型統一寫 `"Microsoft JhengHei", "PingFang TC", sans-serif`**：不外連網路字型，Windows 和 Mac 各有內建的中文字可用。
- **新手樣式用 class，不用 id**：id 留給第 5 章的 JavaScript；整頁共通設定（`body`、`a`、`button`）才用標籤選取器。
- **Flexbox 只教四個屬性**（`display: flex`、`gap`、`justify-content`、`align-items`），不教 grid。
- **試試看裡用色塊代替大頭照**：預覽框放不了讀者的圖片，用圓形 `div` 示範圓角與並排。
- **「CSS 寫在哪裡」的三張卡不放程式碼**：一長串程式碼在窄卡片裡會斷成好幾行，改放白話說明，程式碼放在下面各自的小節。

## 2026-10-23 第 5 章

- **只教「看得懂、改得動」的一小組寫法**：`let`／`const`、雙引號文字、`+` 接字、具名 `function`、`addEventListener`、`getElementById` 搭配 `textContent`／`style`／`value`。`var`、箭頭函式、反引號樣板字串只在「跟 AI 一起做」提一句「看到認得就好」。代價是 AI 寫的程式常跟文章寫法不同，所以那一節教讀者請 AI 加註解、換成簡單寫法。
- **不教迴圈、`Math.random`、`querySelector`、`innerHTML`、`classList`、`localStorage`**：留給實戰範例當場教（午餐抽籤用隨機、待辦清單用儲存）。陣列只教建立、編號從 0、`length`、`push`，給午餐抽籤範例用。
- **多教了讀輸入框的 `.value`**（原規劃只有 `getElementById` 與 `textContent`）：部門聚餐報名表範例一定會用到，而且「輸入名字打招呼」比單純改字更像真的互動。
- **切換狀態一律用 `if (isMorning) { isMorning = false; … } else { … }`**，不用 `!` 反轉：少一個新符號，練習和試試看的寫法一致。
- **試試看不用 `alert`／`prompt`／`console.log`**：預覽框是 sandbox，彈出視窗會被擋並噴錯；結果一律寫到畫面上的元素。
- **夜間模式加分題只換整頁背景、卡片維持白色**：若連卡片文字一起改成淺色，第 4 章做的淺藍色興趣標籤會變成淺字配淺底，看不清楚。

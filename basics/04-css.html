CSS：網頁的衣服

HTML 決定網頁上有什麼，CSS 決定它們看起來的樣子：顏色、字、留白和排版。這一章學會幫網頁「穿衣服」，把你的自我介紹頁變成一張好看的卡片。

閱讀 40 分練習 40 分

學完這篇，你會

  • 知道 CSS 寫在哪裡，看得懂「選取器 { 屬性: 值; }」這種規則。
  • 會用 class 替指定的元素改顏色、字型、背景和邊框。
  • 理解 padding、border、margin 的差別，能把內容置中、用 flex 排成一排。
  • 會用開發者工具試改 CSS，並請 AI 一次只改一件事。

CSS 是什麼？

第 1 章用過一個比喻：HTML 是骨架，決定頁面上有哪些東西：標題、段落、圖片。CSS 則是衣服，決定這些東西看起來是什麼樣子：顏色、大小、位置、間距。

同一份 HTML，換一套 CSS，看起來可以完全不同。以第 3 章的自我介紹頁為例：

📄

樸素版

黑色的字、白色的底，所有東西從左上角一路排下來。內容都在，只是沒有打扮。

🎨

有顏色版

標題變成藍色，段落的字變大，整頁看起來有了重點。骨架一樣，只是換了顏色和字級。

✨

卡片置中版

內容放進白色的卡片裡，整個置中，背景是淡淡的灰色。骨架還是同一份。

本章會教三件事：改顏色與字、留空間、排版置中。最後，我們會幫第 3 章的自我介紹頁換上一套新衣服。

CSS 寫在哪裡

CSS 可以寫在三個地方：

①

style 屬性

直接寫在標籤上，只影響那一個元素。不建議，但要認得。

②

style 標籤

寫在 head 裡，只影響這一頁。本章的試試看都用這種。

③

獨立的 style.css

另存成一個檔案，很多網頁可以共用。最推薦。

style 屬性：寫在標籤上（不建議）

把 style 屬性直接寫在標籤裡，它只影響這一個元素。

<p style="color: #2563eb;">這段是藍色的。</p>

這種寫法的問題是：每個標籤都要自己寫一次。想把全部的段落改成別的顏色，就得一個一個找、一個一個改，很麻煩。不過請 AI 幫忙寫網頁時，它有時會用這種寫法，所以看到的時候要認得它。

style 標籤：寫在 head 裡（本章的試試看都用這種）

把 CSS 放在 head 裡的 <style> 標籤中間。它只影響這一頁。本章的「試試看」都用這種寫法，因為試試看只有一個檔案。

<head>
    <meta charset="utf-8">
    <title>我的小網頁</title>
    <style>
        p {
            color: #2563eb;
        }
    </style>
</head>

獨立的 style.css：推薦

把 CSS 另外存成一個檔案，檔名叫 style.css，放在作品資料夾 my-first-web/ 裡。這是最推薦的寫法，因為多個網頁可以共用同一件「衣服」。改一次 style.css，所有接上它的網頁都會跟著變。

接的方式，是在 head 裡、title 下面加一行 link：

<head>
    <meta charset="UTF-8">
    <title>王小明的自我介紹</title>
    <link rel="stylesheet" href="style.css">
</head>

href 和第 3 章的連結一樣，是相對路徑。意思是從 index.html 出發，往旁邊找到 style.css。兩個檔案放在同一個資料夾裡，所以只要寫檔名就好。

常見錯誤

寫了 link，但樣式沒有出現，常見的原因有三個：

  • 檔名打錯。style.css 和 styles.css 是不同的檔案。
  • 檔案不在同一個資料夾。style.css 要和 index.html 放在一起。
  • 忘了存檔。在 VS Code 按 Ctrl + S（Mac 是 ⌘ + S），再重新整理瀏覽器。

一條規則的長相

CSS 的基本單位叫做規則（rule）。先看一個例子。這條規則會讓所有段落變成藍色，字也會變大：

p {
    color: #2563eb;
    font-size: 18px;
}

這條規則可以拆成三個部分，用三張卡片來看：

①

選取器

要穿衣服的是誰。上面的 p 代表「所有的段落」。

②

屬性

要改什麼。color 是文字的顏色，font-size 是文字的大小。

③

值

改成什麼。#2563eb 是一種藍色，18px 是 18 像素。

再看符號的角色：

  • 大括號 { }：把這條規則的內容包起來，像標籤把內容包起來一樣。
  • 冒號 :：分開「屬性」和「值」。左邊是屬性，右邊是值。
  • 分號 ;：放在每一行的最後，表示這一行結束。

一個規則可以有很多行「屬性: 值;」。一行寫一個屬性，比擠在同一行好讀。

補充

第 3 章學過 HTML 的屬性（attribute），例如 href、src。CSS 的屬性（property），例如 color，是另一回事。兩者中文都叫「屬性」，但 HTML 的屬性是標籤裡的補充資料，CSS 的屬性是規則裡要改的項目。看到的時候分清楚就好。

認識色碼

#2563eb 這種寫法叫做色碼。開頭的 # 後面接六個字，可以是數字或英文字母。每兩個字代表紅、綠、藍三種光的多寡。這些你不用背，也不用算。在 VS Code 裡，寫色碼時旁邊會出現一個小色塊。點一下它，就能用調色盤挑顏色，挑好後 VS Code 會自動換成色碼。

CSS 的註解

CSS 的註解寫成 /* … */，和 HTML 的 <!-- --> 不一樣。

/* 這是 CSS 的註解：段落用藍色 */
p {
    color: #2563eb;
}

常見錯誤

CSS 最麻煩的地方，是寫錯了它不會報錯，整條規則只是悄悄地不生效。最常見的有三種：

  • 用中文輸入法打出全形的符號：冒號「：」、分號「；」、大括號「｛｝」。看起來和半形一樣，但 CSS 不認得，整條規則就會失效。
  • 漏掉分號。少了分號，下一行也會跟著一起失效。
  • 屬性名稱拼錯，例如把 color 寫成 colour。

建議寫 CSS 時，把輸入法切換成英文。遇到樣式沒有生效，先檢查這三件事。

選取器：決定誰要穿這件衣服

規則最前面的那個字，叫做選取器（selector）。它決定這條規則要套用到哪些元素。最基本的選取器有三種。

標籤選取器：所有的 p

直接寫標籤的名稱，例如 p、h1。這樣整頁所有這種標籤都會套用到。

p {
    color: #2563eb;
}

class 選取器：貼了同一個記號的一群

class 選取器前面要加一個點 .。在 HTML 端，用 class 屬性貼上記號：

.highlight {
    background-color: #fef08a;
    font-weight: bold;
}
<p class="highlight">這一段會被畫上螢光筆。</p>

class 可以重複用在很多元素上。一個元素也可以同時有好幾個 class，中間用空白隔開：

<p class="highlight big">這一段同時有兩個 class。</p>

id 選取器：每個人只有一組的號碼

id 選取器前面要加一個井字號 #。在 HTML 端，用 id 屬性：

#intro {
    font-size: 20px;
}
<p id="intro">這是自我介紹的開頭段。</p>

一頁裡，同一個 id 只能出現一次。

👔

class 像制服

很多人可以穿同一套制服。同一個 class 可以貼在很多元素上。

🪪

id 像身分證字號

每個人只有一組。同一頁裡，一個 id 只能給一個元素。

小提示

新手的原則很簡單：樣式一律用 class。id 留給之後 JavaScript 找元素時用（第 5 章）。第 3 章的表單裡，label 的 for 對應的也是 id，那是 id 的另一種用途。

div：空盒子

div 是一個沒有特別意義的「空盒子」。它本身不代表任何內容，只是把幾個元素包在一起，好一起套上樣式。後面做卡片和排版時會常用到它。

<div class="card">
    <h3>我的興趣</h3>
    <p>爬山、看電影、做咖啡。</p>
</div>

上面的 div 把標題和段落包成一組。之後只要替 .card 寫一條規則，裡面的東西就會一起換衣服。

好幾條規則都管到同一個元素時

一個元素可能同時被好幾條規則管到，這時候誰說了算？先記住下面三個概念就夠了。

繼承：外面的衣服會穿到裡面

在 body 設定的文字顏色和字型，裡面的文字都會跟著變。這叫做繼承。所以字型通常設在 body，整頁一次就到位：

body {
    font-family: "Microsoft JhengHei", "PingFang TC", sans-serif;
    color: #1f2937;
}

後寫的蓋前面

同一個選取器寫了兩次，而且設定了同一個屬性，那麼後面那一條為準。

p {
    color: red;
}

p {
    color: blue;
}

上面的段落會是藍色，因為藍色那條寫在後面。

越精準越優先

class 比標籤選取器精準，所以會贏過標籤選取器。例如 .highlight 會贏過 p，就算 p 寫在後面也一樣。

補充

有時候會看到 AI 寫 !important，例如 color: red !important;。它的意思是「硬性蓋過其他規則」。新手先不要用它，因為它會讓之後的修改變得很難。看到 AI 這樣寫，可以請它換成別的寫法，例如把選取器寫得更精準。

試試看：替段落換衣服

下面的小網頁已經寫好了 CSS。請動手做三件事，並觀察右邊預覽的變化：

  1. 把 h1 的顏色換成別的顏色，例如 green（綠色）。
  2. 把 class="highlight" 加到另一個段落上，例如第一段。
  3. 故意把某一個分號「;」改成全形的「；」，看看會發生什麼事。看完再改回來。

文字：顏色、大小與字型

網頁的衣服，先從文字開始。文字有四件事可以設定：顏色、大小、字型，還有行與行之間的距離。

我們先用 color 設定文字的顏色。顏色可以寫英文名字，例如 red，但更常用的是前面介紹過的色碼。例如 #2563eb 是一種藍色，#333333 是接近黑的深灰色。

文字大小用 font-size，單位一律用 px（像素）。16px 是一般閱讀的大小，32px 大約是大標題。

字型用 font-family。本站統一使用下面這一行：

font-family: "Microsoft JhengHei", "PingFang TC", sans-serif;

為什麼要列好幾個？因為每台電腦裝的字型不一樣。Windows 通常有「微軟正黑體」（Microsoft JhengHei），Mac 通常有「蘋方」（PingFang TC）。瀏覽器會從左到右找：第一個找得到就用它；找不到，就換下一個。最後的 sans-serif 是「無襯線字」，代表什麼字型都沒有時，就用系統預設的無襯線字。

line-height 是行高，也就是兩行文字之間的距離。中文字比較方塊，行高太小會擠在一起，看起來很累。中文建議設在 1.6 到 1.8 之間。

這裡要特別注意：行高的值不加 px，直接寫倍數。1.7 的意思是「字的大小乘以 1.7」。這是少數不用加 px 的屬性值，寫成 1.7px 反而會失效。

文字的左右位置用 text-align。left 是靠左，center 是置中。想讓文字變粗，用 font-weight: bold;，效果和 HTML 的 strong 類似。

下面的範例把字型和行高設在 body。body 是整頁的外框，設在這裡，底下所有的文字都會繼承這些設定，不必每一段都重寫。

body {
    font-family: "Microsoft JhengHei", "PingFang TC", sans-serif;
    font-size: 16px;
    line-height: 1.7;
    color: #333333;
}

h1 {
    color: #2563eb;
    font-size: 32px;
    text-align: center;
}

小提示

字型和行高設在 body，整頁都會繼承，最省事。只有某一個標題要特別的顏色時，才另外寫在標題的規則裡。

背景、邊框與圓角

文字設定好了，接下來是「區塊」的外觀。一段內容常常要放在一個有底色、有框線的卡片裡，這就需要下面三個屬性。

background-color 設定背景色，例如 background-color: #f5f7fa; 會讓區塊變成淡淡的灰藍色。

border 設定邊框，一行就包含三個值：

border: 1px solid #ddd;
  • 1px：粗細，線有多粗。
  • solid：樣式，實線。另外還有 dashed（虛線）等，先用實線就好。
  • #ddd：顏色，淺灰色。

三個值用空白隔開，順序不能亂。

border-radius 設定圓角。數字越大，角就越圓。border-radius: 12px; 會讓四個角都變圓一點點。

下面的範例，把一個 .card 加上淺色背景、邊框和圓角。.card 是我們自己取的 class 名字，前面學過，用 . 開頭的選取器可以選到所有 class="card" 的元素。

.card {
    background-color: #f5f7fa;
    border: 1px solid #ddd;
    border-radius: 8px;
}

背景和文字要搭配好，才看得清楚。顏色對比太低，就算設定正確，讀的人也會覺得吃力。

✗ 顏色對比太低

background-color: #ffffff; 配上 color: #cccccc;

淺灰字配白底，看不清楚，像是快要消失的字。

✓ 顏色對比清楚

background-color: #f5f7fa; 配上 color: #333333;

深色字配淺色底，一眼就能看清楚。

寬度與圖片大小

區塊要多寬，用 width 設定。例如 width: 200px; 會讓區塊固定是 200 像素寬。

max-width 是「最寬不能超過」。它的意思是：可以比較窄，但不能超過這個數字。

圖片最需要這兩個屬性。手機拍的照片原始尺寸很大，可能有好幾千像素寬。如果不設定，它會直接撐爆整個頁面，讀的人要左右拖拉才看得到。

img {
    width: 200px;
}

上面這行會讓所有圖片都固定是 200 像素寬。高度會跟著等比例變化，圖片不會變形。

如果希望圖片跟著外框的寬度，但又不要超過外框，可以用 max-width: 100%;。它的意思是「最寬是外框的 100%」，外框窄，圖片就跟著變窄；外框寬，圖片也不會超過它。

img {
    max-width: 100%;
}

想把大頭照變成圓形，就用 border-radius: 50%;。50% 代表圓角的半徑是寬度的一半，正方形的四個角就會被切成圓形。要注意，圖片的寬和高必須一樣，才會是正圓；如果寬高不同，會變成橢圓。

.avatar {
    width: 120px;
    height: 120px;
    border-radius: 50%;
    object-fit: cover;
}

height 是高度，寫法跟 width 一樣。object-fit: cover; 的作用是：如果照片的長寬比例不對，讓它填滿方框，多出來的部分裁掉。這一行目前照抄即可，之後需要時再回來細看。

常見錯誤

只設 width 時，圖片會等比例縮放，不會變形。同時設了 width 和 height，卻沒有加 object-fit: cover;，照片就會被壓扁或拉長。大頭照要變圓時，寬和高寫成一樣的數字，再加上 object-fit: cover;。

盒子模型：padding、border、margin

CSS 有一個很重要的觀念：每個元素都是一個盒子。段落是盒子，圖片是盒子，卡片也是盒子。盒子由內到外，分成四層：

  1. 內容（content）：盒子裡面真正的東西，例如文字或照片。
  2. padding（內距）：內容和邊框之間的留白。
  3. border（邊框）：盒子的框線。
  4. margin（外距）：盒子和別的盒子之間的距離。

可以把它想成相框。照片就是內容；照片和相框之間會墊一張襯紙，這就是 padding；相框本身是 border；掛在牆上時，相框和相框之間、相框和牆壁之間的距離，就是 margin。

🖼️

padding：襯紙

盒子裡面的留白。數字越大，內容離框線越遠。

padding: 16px; 代表四邊都留 16 像素。

🟫

border：相框

盒子的框線。寫法是「粗細 樣式 顏色」。

border: 1px solid #ddd; 是一條淺灰色的細實線。

↔️

margin：牆面距離

盒子外面的距離，把它和別的盒子隔開。

margin-bottom: 24px; 會讓它和下面的內容隔開 24 像素。

三個屬性的寫法都一樣。padding: 16px; 只寫一個數字，就是四邊都一樣。如果想分開設定，可以依序寫上、右、下、左，但先記得「一個數字，四邊相同」就夠了。

有一招在做卡片時非常常用，就是讓盒子左右置中：

.box {
    max-width: 600px;
    margin: 0 auto;
}

margin: 0 auto; 的意思是：上下的外距是 0，左右的外距是 auto（自動）。左右的空間會被平均分給兩邊，盒子就正好置中。

要注意，這招需要搭配 max-width（或 width）。盒子如果沒有設定寬度，會直接撐滿整個外框，左右就沒有空間可以分，置中也就看不出來。

下面是一個完整的卡片範例，把這一節學到的東西全部用上。

.card {
    max-width: 600px;
    margin: 0 auto;
    padding: 24px;
    border: 1px solid #ddd;
    border-radius: 12px;
    background-color: #fff;
}

這張卡片最寬 600 像素，左右置中；內容和邊框之間留 24 像素；邊框是淺灰色的細線，四個角是圓的；背景是白色。

補充

一開始看到 padding 和 margin 很容易搞混。記法是：padding 在框的裡面，margin 在框的外面。

用開發者工具看 CSS、直接改改看

規則寫多了，常常會搞不清楚「到底是哪一條規則讓這行字變成藍色」。開發者工具可以直接告訴你答案，而且還能即時改數字。

  1. 右鍵「檢查」在網頁上想看的地方按右鍵，選「檢查」。
  2. 選到元素開發者工具會反白對應的 HTML 元素。滑鼠移過去，網頁上也會標出它的範圍。
  3. 看 Styles 面板Styles 面板會列出套用在這個元素上的所有規則，以及它來自哪一個檔案。
  4. 點值直接改點一下數字，直接改成別的值，網頁立刻變化。勾選框則可以暫時關掉某條規則。

在 Styles 面板裡，有時會看到某一條規則的文字上有一條橫線，像是被刪掉一樣。這表示這條規則被別條蓋過了。這跟前面學過的「後寫的蓋前面」是同一個道理：同一個屬性，只會有一個值生效，其他的會被蓋掉。

Styles 面板的最下面，還有一個盒子圖，用不同的顏色標出 margin、border、padding 和內容的大小。想確認某個盒子的內距到底是多少，看這裡最快。

常見錯誤

在開發者工具裡改的數字，只是暫時的。重新整理頁面，就會回到原來的樣子。調到滿意之後，記得把數字抄回 style.css，不然下次打開還是舊的。

試試看：做一張名片卡

這一節的最後，我們用學過的東西做一張名片卡。下面的小網頁，CSS 寫在 <style> 裡面。

試試看只有一個檔案，讀不到外部的 style.css，也放不了真的照片。所以大頭照用一個藍色的圓形色塊，中間放一個「王」字代替。

動手前，可以先試試下面三件事，觀察預覽的變化：

  • 把 .card 裡的 padding 改成 0，再改成 48px，比較卡片內容和邊框之間的距離。
  • 把 .card 裡的 border-radius 改成 40px，看看四個角變成什麼樣子。
  • 把 .card 裡的 margin 改成 40px 0（左右改成 0），看看卡片跑去哪裡了。改回 40px auto 後，再和前一個結果比較。

試著改完之後，你會發現：margin: 40px auto; 裡的 auto 負責左右置中，少了它，卡片就會靠到左邊去。這就是前面說的置中招式。

Flexbox：讓東西排成一排

你可能已經發現，h1、p、div、ul 這類元素，預設會一個疊一個往下排。如果想讓幾個盒子並排，就要請 CSS 幫忙安排，這個工具叫做 Flexbox（彈性盒子）。

你可以把它想成排隊：一群人站在同一條隊伍裡，從左到右排成一排。要讓裡面的盒子排成一排，就在它們的外層盒子上寫 display: flex;，意思是「請裡面的東西排隊」。

常見錯誤

display: flex; 要寫在外層的盒子上，寫在裡面的小盒子上沒有效果。例如要讓標籤排成一排，要寫在 ul 上，不是寫在每一個 li 上。

本節只需要記得四個屬性：

  • display: flex;：寫在外層，讓裡面的盒子排成一排。
  • gap：盒子和盒子之間的距離，例如 gap: 8px;。
  • justify-content：橫向怎麼分配。flex-start 是靠左（預設），center 是置中，space-between 是第一個靠左、最後一個靠右，中間的距離平均分開。
  • align-items：直向怎麼對齊。center 是上下置中，常用在大頭照和文字並排的時候。

第一個例子，把「我的興趣」做成一排小標籤。HTML 先寫一個 ul，並加上 class="tags"：

<h2>我的興趣</h2>
<ul class="tags">
    <li>爬山</li>
    <li>看電影</li>
    <li>做咖啡</li>
</ul>

CSS 這樣寫：

/* 外層：讓裡面的 li 排成一排，間距 8px */
.tags {
    display: flex;
    gap: 8px;
    list-style: none;
    padding: 0;
}

/* 每一個小標籤：背景色、圓角、內距 */
.tags li {
    background-color: #dbeafe;
    border-radius: 16px;
    padding: 4px 12px;
}

其中 list-style: none; 和 padding: 0; 是什麼？ul 預設會在每一項前面加上圓點，而且整個清單會往右縮排。list-style: none; 是把圓點拿掉，padding: 0; 是把預設的縮排拿掉。這兩行只是為了讓清單看起來像標籤，本節不用特別記。

第二個例子，大頭照和名字左右並排。這時候要用 div 把兩個東西包在一起，外層的 div 加上 class="profile"：

<div class="profile">
    <img class="avatar" src="images/me.jpg" alt="王小明的大頭照">
    <h1>王小明</h1>
</div>
.profile {
    display: flex;
    align-items: center;
    gap: 16px;
}

align-items: center; 讓照片和名字在上下方向置中對齊，gap: 16px; 讓它們之間留出一點空白。

跟 AI 一起做：一次只改一件事

CSS 的屬性有成千上百個，沒有人會全部背起來。寫 CSS 的時候，你可以請 AI 幫忙寫，這是很實用的做法。

跟 AI 一起做

但有兩件事要注意：

  1. 一次只要求一件事。每次只請 AI 改一個地方，改完打開畫面確認，再進行下一步。如果一次改太多，畫面出問題的時候，你就不知道是哪一行造成的。
  2. 請 AI 解釋它寫的每一行。看不懂的屬性，直接問它「這一行是在做什麼？」，不要照單全收。

下面是一段可以直接複製的提示詞，請 AI 幫你替自我介紹頁寫 style.css：

對 AI 這樣說

這是我的自我介紹頁 HTML（貼上 index.html）。請幫我寫一個 style.css：把整頁內容放在一張置中的白色卡片裡，背景用淺灰色，字型用微軟正黑體。只寫 CSS，不要改 HTML 的結構；如果一定要加 class，請告訴我要加在哪一行。每一條規則上面加中文註解，說明它在做什麼。

提示詞寫得清楚不清楚，AI 給的結果也會不一樣：

✗ 這樣不好

「幫我把網頁弄漂亮」

範圍太模糊，AI 可能整個重寫，還會加上一堆你沒學過的東西，改完也不知道哪裡變了。

✓ 這樣比較好

說清楚要改哪裡、改成什麼樣子，而且一次一件事。例如：「請把內容放進白色卡片，卡片置中」。

範圍小，改完容易檢查，出錯也容易找到原因。

常見錯誤

AI 常會寫出你還沒學過的東西，例如 grid、@media、!important、rem。看不懂的時候，可以問它「這一行在做什麼？可以用比較簡單的寫法嗎？」。另外，貼上去之前，先把原本的 style.css 複製成 style-backup.css 留作備份，萬一改壞了，還可以拿回來。

重點回顧

  • CSS 寫在 style.css：在 head 裡用 <link rel="stylesheet" href="style.css"> 接上，檔名和路徑要一致。
  • 規則的格式：選取器 + 大括號，裡面是「屬性: 值;」。冒號、分號、大括號都要用半形，全形符號會讓樣式失效。
  • 新手樣式用 class：要挑出特定元素時，在 HTML 加上 class="名字"，CSS 寫成 .名字，不要用 id。整頁共通的設定（例如 body）才用標籤選取器。
  • 常用屬性：顏色、字的大小和字型、行高、背景色、邊框與圓角、寬度與最大寬度。
  • 盒子模型與置中：內距 padding 在內側，外距 margin 在外側；寫 max-width 搭配 margin: 0 auto; 就能讓盒子置中。
  • flex 寫在外層：要讓東西排成一排，display: flex; 寫在外層盒子上。請 AI 寫 CSS 時，一次只改一件事，改完確認再繼續。

動手做

替第 3 章的自我介紹頁換上衣服。

  1. 新增 style.css。在 my-first-web 資料夾裡（和 index.html 放在同一層），新增一個檔案，名稱是 style.css。
  2. 在 index.html 接上 style.css。在 head 裡、title 的下面加一行：<link rel="stylesheet" href="style.css">。
  3. 設定 body。在 style.css 寫 body 的規則：淺灰色背景、微軟正黑體、行高 1.8、文字顏色。存檔後確認畫面有變。如果沒變，看本節最下面的「樣式沒出現，或排版怪怪的？」。
  4. 加上白色卡片。在 index.html 的 body 裡，用 <div class="card"> 把所有內容包起來。在 style.css 寫 .card：白色背景、最大寬度 640px、margin: 40px auto;、內距、圓角、邊框。
  5. 讓大頭照變圓。在 img 加上 class="avatar"。在 style.css 寫 .avatar：寬高 120px、border-radius: 50%;、object-fit: cover;。

樣式沒出現，或排版怪怪的？
  • link 接錯了：href 的檔名要和 style.css 完全一樣，而且 style.css 必須和 index.html 放在同一個資料夾。
  • 用了全形符號：冒號 ：、分號 ；、大括號 ｛｝ 都是全形，瀏覽器看不懂，整條規則就會失效。要改成半形。
  • class 名稱對不上：CSS 要加點，HTML 不加點。HTML 寫 class="tags"，CSS 就寫 .tags。大小寫也要一樣。
  • flex 寫錯地方：display: flex; 要寫在外層的 ul（或 div）上，不是寫在裡面的 li 上。
  • 改了沒存檔，或瀏覽器沒重新整理：先按 Ctrl + S（Mac 是 ⌘ + S），再重新整理瀏覽器。
  • 用開發者工具檢查：在元素上按右鍵「檢查」，看 Styles 面板。如果你寫的規則沒有出現，代表選取器沒有對到元素；如果規則出現了但被劃掉，代表它被後面的另一條規則蓋過了。

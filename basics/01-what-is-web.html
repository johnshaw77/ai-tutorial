網頁是什麼？

你每天都在看網頁，但它到底是什麼？這一章用白話帶你看懂網頁背後的三個角色，以及一個小秘密：網頁其實就是文字檔。

閱讀 20 分練習 10 分

學完這篇，你會

  • 理解「網址」、「伺服器」、「瀏覽器」三者的關係。
  • 知道網頁其實就是「文字檔」，用記事本就能寫。
  • 知道 AI 在這門課扮演什麼角色。

你每天都在用網頁

早上打開 Google 查天氣，中午在內部系統填請假單，晚上在 YouTube 看影片。這些畫面都是「網頁」。

網頁看起來很複雜，但拆開來只有幾個簡單的角色。接下來我們一步一步看。

輸入網址後發生什麼事？

你在網址列輸入網址、按下 Enter，到畫面出現，中間大約經過四個步驟。可以把它想成「點餐」或「外送」。

  1. 輸入網址像在餐廳跟服務生說：「我要點這一道菜。」
  2. 找到伺服器瀏覽器把網址送到網路上，找到存放網頁的電腦（伺服器），像找到廚房。
  3. 伺服器送回檔案伺服器把網頁檔案打包送回來，像廚房把餐點交給外送員。
  4. 瀏覽器翻譯成畫面瀏覽器讀懂檔案，變成你看到的文字、圖片和按鈕。

第一步輸入的「網址」，就是你要去的地址。以 https://example.com/lunch/menu.html 為例，可以這樣拆開：

  • https://：協定，代表用什麼方式傳送。https 表示有加密，比較安全。
  • example.com：網域，代表這個網站的名字，用來找到伺服器的位置。
  • /lunch/menu.html：路徑，代表要看的是哪一個檔案，像店裡的哪一道菜。

網頁由三種檔案組成

一個網頁通常不是一個檔案，而是三種角色合作。可以拿一個人來比喻：

🦴

HTML

骨架。決定頁面有哪些內容，例如標題、段落、按鈕。就像人的骨頭，沒有它就沒有形狀。

<h1>午餐時間</h1>

👕

CSS

衣服。決定外觀，例如顏色、字體大小、版面位置。就像人穿什麼衣服。

h1 {
  color: red;
}

🕺

JavaScript

動作。決定互動，例如按下按鈕後要做什麼。就像人會動、會回應。

alert('你好！');

網頁其實就是文字檔

這是很多人會驚訝的地方。網頁檔案本質上就是一般的文字，只是副檔名不同。

網頁的副檔名通常是 .html，例如 index.html。裡面寫的就是前面看到的標籤和樣式，用記事本打開也看得到。

所以你不需要昂貴的軟體，用記事本就能開始寫網頁。

常見錯誤

Windows 使用者：預設可能隱藏副檔名，檔案會變成 hello.html.txt，瀏覽器就打不開。請打開檔案總管，在「檢視」中勾選「副檔名」。

Mac 使用者：「文字編輯」預設會用「富文本」格式存檔，瀏覽器會讀不懂。請在選單選「格式」→「製作純文字」，再存檔。

靜態網站 vs 動態網站

網頁大致分兩種。靜態網站像一張傳單：內容印好了，每個人拿到的都一樣。本課程只做靜態網站。

動態網站像銀行櫃台：會依照你是誰、你輸入什麼，即時給出不同的結果。它需要更多技術，我們之後再談。

AI 在這門課的角色

跟 AI 一起做

這門課會大量使用 AI 協助寫程式。AI 很會寫程式，但偶爾會講錯，而且講得很有自信。

所以把它當成「很會寫程式、但需要你檢查的助理」。要能判斷它寫得對不對，就得先懂基礎，這也是本章的目的。

遇到看不懂的程式碼，可以請 AI 用白話解釋。例如：

對 AI 這樣說

我是完全不會寫程式的新手。請用白話文，逐行解釋下面這段 HTML 在做什麼，每行一句話，不要用專業術語。這段是：<h1>午餐時間</h1>

提問的方式會大大影響回答的品質。比較下面兩種說法：

✗ 這樣不好

「幫我做一個網頁。」

✓ 這樣比較好

「我要做一個公司午餐菜單的網頁，有一個標題和三行菜名。請用 HTML 寫，並用白話說明每一段在做什麼。」

重點回顧

  • 你輸入網址後，瀏覽器會去伺服器拿檔案，再把它畫成畫面。
  • 網頁由 HTML（骨架）、CSS（外觀）、JavaScript（互動）三種檔案組成。
  • 網頁本質是文字檔，副檔名是 .html，用記事本就能寫。
  • 本課只做靜態網站。AI 很能幹但會出錯，所以要先懂基礎才能判斷。

動手做

我們來建立你的第一個網頁檔 hello.html。

  1. 打開編輯工具。Windows 打開「記事本」；Mac 打開「文字編輯」，並選「格式」→「製作純文字」。
  2. 貼上這幾行。按程式碼右上角的「複製」，再貼到編輯工具裡。現在看不懂沒關係，第 3 章會一行一行解釋。 
    <!doctype html>
<html lang="zh-Hant-TW">
<head>
  <meta charset="utf-8">
  <title>你好</title>
</head>
<body>
  <p>你好，我是新手！</p>
</body>
</html>
  3. 存檔成 hello.html。Windows：「存檔類型」選「所有檔案」，檔名輸入 hello.html，編碼選 UTF-8。Mac：存檔時確認檔名是 hello.html，不要多出 .txt。
  4. 用瀏覽器打開。在檔案上雙擊。若是用記事本開啟，請改用右鍵「打開方式」，選 Chrome、Edge 或 Safari。畫面上應該看到「你好，我是新手！」。
  5. 挑戰一下：把「你好，我是新手！」改成你的名字，存檔後回到瀏覽器按 F5（Mac 是 ⌘ + R）重新整理，看看有沒有變。
畫面沒出現，或出現一堆亂碼？
  • 看到的是程式碼本身，不是畫面：副檔名不對。檔名要是 hello.html，不能是 hello.html.txt。
  • 中文變成亂碼：存檔時編碼要選 UTF-8，而且第 4 行的 <meta charset="utf-8"> 不能少，它就是在告訴瀏覽器「這份文字用 UTF-8 讀」。
  • Mac 開出來有奇怪的格式碼：沒有切成純文字。回到「文字編輯」選「格式」→「製作純文字」再存一次。

JavaScript：網頁的動作

HTML 是骨架，CSS 是衣服，JavaScript 讓網頁「動起來」：按下按鈕換一句話、換一個顏色、跟你打招呼。這一章的目標是看得懂、改得動，讓你的自我介紹頁多一顆會回應的按鈕。

閱讀 50 分練習 50 分

學完這篇，你會

  • 知道 JavaScript 寫在哪裡，看得懂變數、文字、數字、布林和陣列。
  • 看得懂 if 判斷和 function，知道程式什麼時候會執行哪一段。
  • 會用 addEventListener 把按鈕接到動作，用 getElementById 改畫面上的字和顏色。
  • 拿到 AI 寫的 JavaScript，能找出要改的文字或數字，改完自己確認結果。

JavaScript 是什麼？

第 1 章說過，網頁由三種東西組成：HTML 是骨架，CSS 是衣服，JavaScript 是動作。前兩章學了骨架和衣服，這一章輪到動作。HTML 決定網頁上有什麼，CSS 決定它們看起來的樣子，而 JavaScript 決定網頁會動：按了按鈕會有反應，輸入的文字會跟著改，時間到了會自動換內容。

🦴

HTML

有什麼：標題、段落、圖片、按鈕。

🎨

CSS

長什麼樣：顏色、大小、位置、間距。

⚡

JavaScript

會做什麼：改掉畫面上的字、回應按鈕、記住一些資料。

JavaScript 是一種程式語言。這一章不要求你從零寫程式，目標是：看到 AI 寫的 JavaScript，認得每一塊在做什麼，也敢改裡面的文字和數字。

JavaScript 寫在哪裡

JavaScript 可以直接寫在 HTML 裡，也可以另外存成一個檔案。本站的做法和 CSS 一樣，推薦另存成 script.js，放在作品資料夾 my-first-web/ 裡，和 index.html 同一層。

在 index.html 裡，用 <script> 標籤把它接上，而且要放在 </body> 的前面：

<body>
    <!-- 頁面的內容寫在這裡 -->

    <script src="script.js"></script>
</body>

這和第 4 章的 link 很像，差別是 script 用的是 src，後面一定要有 </script> 結束標籤，而且要放在最下面。原因是瀏覽器是從上往下讀網頁的。等畫面上的元素都讀完了，才執行 JavaScript，程式才找得到要改的東西。

常見錯誤

如果把 script 放在 head 裡，程式執行時畫面上的元素還沒出現，常常會找不到東西，結果什麼都不會變。檔名打錯或不在同一個資料夾，也會讓程式完全不動。

第一支程式：改掉畫面上的字

假設 index.html 裡有一段文字，我們替它加上一個 id。第 4 章說過，id 就是讓 JavaScript 找到元素用的：

<p id="greeting">你好，歡迎來到我的網頁。</p>

接著在 script.js 寫下這一行：

document.getElementById("greeting").textContent = "很高興認識你！";

存檔、重新整理瀏覽器，畫面上的字就變成「很高興認識你！」。這一行看起來很長，我們拆開來看：

  1. document整份網頁。可以想成拿著整棟房子的平面圖。
  2. getElementById用 id 找到元素。括號裡的 "greeting" 就是 id 的名字，要加引號。
  3. .textContent這個元素的文字內容。中間的點，意思是「它的」。
  4. = 新的文字把文字換成等號右邊的「很高興認識你！」，最後用分號結束。

整句念起來就是：「在整份網頁裡，找到 id 是 greeting 的元素，把它的文字內容換成『很高興認識你！』。」

以後看到 AI 寫的 JavaScript，大部分都是這個模式：先找到元素，再改它的某個部分。

常見錯誤

getElementById 的大小寫要完全一樣，I 和 D 都要大寫。括號、引號和分號也要用半形，中文輸入法打出的全形符號，會讓整支程式不動。

變數：貼標籤的收納盒

寫程式時，常常需要先把一個東西存起來，等一下再拿出來用。存東西的地方叫做變數（variable）。可以把它想成一個貼了標籤的收納盒：盒子外面的標籤是變數的名字，盒子裡放的是值（value）。

let myAge = 30;

這一行可以拆成四部分：

  • let：告訴電腦「我要準備一個新的盒子」。
  • myAge：盒子外面的標籤，也就是變數的名字。
  • = 30：把右邊的 30 放進盒子裡。
  • ;：分號，表示這一行結束。

let 和 const：會換的盒子，不會換的盒子

盒子分兩種。裡面的東西可能會換的，用 let；從頭到尾都不會換的，用 const（constant，常數）。

下面程式碼裡，// 後面的中文是註解，和 HTML 的 <!-- --> 一樣，是寫給人看的說明，電腦會跳過它。

let myAge = 30;                  // 會變的：之後可以改成 31
const myName = "王小明";         // 不會變的：名字通常不改

本章的規則很簡單：會變的用 let，不會變的用 const。拿不定主意時，先用 let 就好。

變數的名字怎麼取

變數名字用英文，習慣寫成「小駝峰」：第一個字小寫，後面每個字的開頭大寫，例如 greetingText、isMorning。第二個字開頭大寫，是習慣寫法，讓讀的人一眼看出它是好幾個字接在一起。名字中間不能有空白。

補充

a、x 這種名字電腦也認得，但過了一個禮拜，你自己可能也想不起它是什麼。取名字的原則是：看名字就知道裡面放的是什麼。

三種資料：文字、數字、布林

盒子裡可以放不同種類的東西。先認得下面三種，就已經夠用了。

🔤

文字（程式裡叫字串，string）

前後要用雙引號包起來，例如 "王小明"。

🔢

數字

直接寫數字，不加引號，例如 30、3.5。

🔘

布林（true / false）

只有 true（對）和 false（錯）兩種，不加引號。

const myName = "王小明";    // 文字：有雙引號
let myAge = 30;             // 數字：沒有引號
let isOnline = true;        // 布林：只有 true 或 false

常見錯誤

文字一定要加雙引號。"王小明" 是文字，王小明 沒有引號，電腦會以為那是一個變數名字，找不到它就出錯。雙引號也要用半形，不能用中文輸入法打出的「」。

陷阱：文字加數字，結果是文字

加號 + 有兩種用法。數字加數字，就是一般的算術。文字加文字，會把兩段文字接在一起，例如 "名字：" + "王小明" 會變成 "名字：王小明"。只要其中一邊是文字，加號就變成「接起來」。

1 + 1;       // 結果是 2
"1" + 1;    // 結果是 "11"，不是 2

第二行的 "1" 雖然長得像數字，但它加了引號，所以是文字。文字加上 1，電腦就把它們接成 "11"。

常見錯誤

看到一個東西，先看它有沒有引號。30 是數字，可以拿來算；"30" 是文字，即使看起來一樣，加起來也會接在一起。網頁上的數字，有時候是從文字來的，遇到計算結果怪怪的，要先想到這個陷阱。

試試看：改變數的值，畫面跟著變

下面的小網頁已經寫好了 JavaScript，寫在 </body> 前面的 script 標籤裡。程式用加號把說明文字和變數的值接起來，放到畫面上。請動手改這三個地方，觀察預覽的變化：

  1. 把 myAge 的 30 改成 31，看「年齡」那一行的數字有沒有跟著變。
  2. 把 isOnline 的 true 改成 false，看最後一行的字變成什麼。
  3. 把 myName 的 "王小明" 改成你自己的名字。注意前後的雙引號要留著。

改完之後，右邊預覽會自動更新，不用重新整理。想回到原本的程式，按「重設」就可以。

你會發現，盒子裡的值一換，畫面就跟著變。程式做的事情其實很單純：把盒子裡的值取出來，再用前面學過的 textContent，放到畫面上。

陣列：一排有編號的收納盒

如果有很多東西要一起存，例如一週的七個行程，一個一個開盒子就太麻煩了。陣列（array）就像一排有編號的收納盒：所有東西排成一列，用編號就能找到其中一個。

let fruits = ["蘋果", "香蕉", "芭樂"];

fruits[0];          // 蘋果
fruits[1];          // 香蕉
fruits.length;      // 3，一共有 3 個
fruits.push("橘子"); // 在最後面加上一個，現在一共有 4 個

這一小段有四個重點：

  • 中括號 [ ]：把一排東西包起來，中間用逗號分開。
  • 編號從 0 開始：第一個是 [0]，第二個是 [1]，第三個是 [2]。
  • length：這一排一共有幾個。它後面沒有括號，直接讀出數字。
  • push：在最後面加入一個新的東西。

常見錯誤

編號從 0 開始，是新手最容易搞錯的地方。看到「第三個」，要寫 [2]，不是 [3]。[3] 指的是第四個。如果這一排只有三個，[3] 就什麼都拿不到。

下一節會學，如何讓程式根據不同的情況，做不同的事。

條件判斷：如果……就……，不然……

前面學過布林，它只有 true（對）和 false（錯）兩種值。條件判斷就是利用這個「對或錯」，決定程式要走哪一條路。

生活中很常見的例子是：「如果下雨，就帶傘；不然，就不帶。」在 JavaScript 裡，寫法是 if 加上 else：

let score = 80;
let message = "";

if (score >= 60) {
    message = "及格";
} else {
    message = "不及格";
}

拆開來看：

  • if 後面的小括號 ( ) 裡，放的是一個問題，叫做條件。上面的條件是「分數大於或等於 60 嗎？」，答案只會是 true 或 false。
  • 條件是 true 時，就執行第一組大括號 { } 裡的內容。
  • else 的意思是「不然」。條件是 false 時，就執行 else 後面大括號裡的內容。

條件裡常用的比較符號有下面幾個，用來比大小，或比兩邊是不是一樣：

  • ===：等於，兩邊一模一樣才是 true。
  • !==：不等於。
  • >：大於；<：小於。
  • >=：大於或等於；<=：小於或等於。

= 和 === 不一樣

這是新手最容易搞混的地方。一個等號 = 是放進去，把右邊的值存到左邊的變數裡，前面學變數時就是這樣用的。三個等號 === 才是比一比，看左右兩邊是不是一樣，結果是 true 或 false。

所以寫在 if 的小括號裡時，要用三個等號：

✗ 這樣不好

if (score = 60) {

只有一個等號，這行會把 60 存進 score，而不是拿來比較，結果不是你要的。

✓ 這樣比較好

if (score === 60) {

三個等號，是在問「score 是不是 60」。

多個條件：else if

如果情況有三種以上，就用 else if，意思是「否則如果」。程式會從上往下一個一個看，遇到第一個是 true 的條件就停下來，後面的不再看。

let score = 95;
let message = "";

if (score >= 90) {
    message = "優秀";
} else if (score >= 60) {
    message = "及格";
} else {
    message = "不及格";
}

分數是 95 時，第一個條件就成立，得到「優秀」，後面兩個條件都不會再看。

小提示

條件的順序很重要。如果把 score >= 60 放在最前面，95 也會先符合它，永遠到不了「優秀」。

常見錯誤

條件要放在小括號 ( ) 裡，大括號 { } 也不能漏。中文輸入法打出的全形括號、全形等號，程式會整個不動。

函式：把一段步驟取個名字

寫程式時，有些步驟會一做再做，例如「依照分數給評語」。每次都把整段重寫一遍很累，改的時候也容易漏掉。這時候就用函式（function），把一段步驟包起來，取一個名字。

可以把函式想成食譜。食譜先寫好，上面有名字，下面列出步驟。要做菜的時候，只要叫出食譜的名字，照著做就好，不用每次從頭想。

📜

食譜的名字

用 function 開頭，後面接名字和小括號 ( )。大括號裡面寫步驟。

🥚

食材（參數）

小括號裡的名字，是食譜需要的材料，叫做參數。

🍳

開始做（呼叫）

寫下食譜的名字加小括號，食譜就照著做一次。這叫呼叫。

來看一個完整的例子。這段程式假設頁面上有一個 id 是 result 的元素，用來顯示結果：

function showResult(score) {
    let message = "";

    if (score >= 60) {
        message = "及格";
    } else {
        message = "不及格";
    }

    document.getElementById("result").textContent = message;
}

showResult(80);

逐行看：

  • function showResult(score)：定義食譜。食譜叫 showResult，需要一個食材，名字叫 score。
  • 大括號裡的 if 是食譜的步驟，跟前一節學的一樣。
  • document.getElementById("result").textContent = message;：前面學過的寫法，把文字寫到畫面上 id 是 result 的元素裡。
  • showResult(80);：呼叫食譜，食材放 80，所以 score 這一次就是 80。

同一個食譜可以換不同的食材，所以寫一次，就能用很多次。把最後一行改成 showResult(45);，就會得到「不及格」。

函式的名字寫法和變數一樣：第一個字小寫，後面每個字的開頭大寫，例如 showResult。這叫小駝峰，是習慣寫法，讓人一眼看出它是由好幾個字組成的。

常見錯誤

只寫 function 卻沒有呼叫，畫面上什麼都不會發生。食譜寫好了，還要「叫它做」才會動。

試試看：依分數顯示評語

下面的小網頁裡有一個 showResult 函式，裡面用 if 判斷分數。最後一行呼叫它時，給的分數是 75，所以預覽一開始會顯示「及格，還可以再加油。」

請動手做兩件事，觀察預覽的變化：

  1. 把最後一行的 showResult(75); 改成 showResult(95);，看看文字變成什麼。
  2. 再改成 showResult(50);，確認它會顯示「不一樣」的評語。

改完右邊的預覽會自動更新。改壞了，可以按「重設」，回到原本的程式。

事件：按一下就做事

網頁上很多動作，都是「使用者做了某件事」才發生的，例如點按鈕、按鍵盤。這種「使用者做了某件事」，叫做事件（event）。最常見的是點擊，英文叫 click。

要讓按鈕在被點的時候執行函式，要用 addEventListener（加上事件聆聽）。先看一個例子，這是一般的寫法：

const changeBtn = document.getElementById("change-btn");

changeBtn.addEventListener("click", changeGreeting);

逐行看：

  • 第一行：用前面學過的 getElementById，找到 id 是 change-btn 的按鈕，存進 changeBtn 裡。這個名字不會再改，所以用 const。
  • 第二行：意思是「changeBtn 這顆按鈕，聽到 "click"（被點擊），就去執行 changeGreeting 這個函式」。
  • "click" 是事件的名字，要用英文和雙引號。
  • 後面的 changeGreeting 只寫名字，不加小括號。等按下去的時候，程式才會去執行它。

常見錯誤

如果寫成 changeBtn.addEventListener("click", changeGreeting());，多了小括號，函式會在頁面一載入就執行，而不是等按下去才執行。名字後面不要加小括號。

看到 onclick 認得就好

有些 AI 寫的網頁，會把事件直接寫在按鈕的標籤上：

<button onclick="changeGreeting()">切換問候語</button>

這是另一種寫法，效果差不多。看到的時候認得它就好。本站的範例統一用 addEventListener，所以之後寫的 JavaScript 也會用這一種。

試試看：按一下切換問候語

下面的小網頁有一顆按鈕。每按一次，問候語就在「早安！」和「午安！」之間切換。

這裡要解決一個問題：函式本身不會記得上一次做了什麼。所以我們用一個布林變數 isMorning（意思是「是不是早上」）把現在的狀態記下來。isMorning 是 true，就代表現在顯示「早安！」；按一次，就把它改成 false，同時換成「午安！」。

程式裡的 if (isMorning) 是簡寫。isMorning 本身就是 true 或 false，所以不用再寫 === true，意思就是「如果現在是早上」。

動手做兩件事，觀察預覽的變化：

  1. 按幾次按鈕，看看「早安！」和「午安！」會不會來回切換。
  2. 把程式裡的 "午安！" 改成 "晚安！"，再按按鈕看看。

改完右邊的預覽會自動更新。改壞了，可以按「重設」，回到原本的程式。

改更多東西：換顏色、讀輸入框

前面我們用 textContent 改畫面上的文字。其實元素還能改樣式，例如文字的顏色、大小、背景色。寫法是在元素後面接 style，再接 CSS 的屬性名稱，最後用等號指定新的值：

// 找到 id 是 "title" 的元素
const title = document.getElementById("title");

// 把文字的顏色改成紅色
title.style.color = "red";

// CSS 的 background-color，在 JavaScript 要寫成 backgroundColor
title.style.backgroundColor = "#fef08a";

// 文字大小的值要放在引號裡，單位 px 也一起放進去
title.style.fontSize = "32px";

寫的時候要注意三件事：

  • CSS 的減號要拿掉，改成小駝峰。background-color 在 JavaScript 要寫成 backgroundColor：拿掉減號，減號後面的字母改成大寫。font-size 也是一樣，寫成 fontSize。
  • 值要用引號包起來。顏色和大小都是文字，例如 "red"、"32px"。32px 沒有加引號，程式會看不懂。
  • 寫錯名字，不一定會報錯。如果寫成 title.color，少了中間的 style，程式不會報錯，畫面也不會變。這跟 CSS 寫錯時「悄悄不生效」很像。

另一件常用的事，是讀取輸入框裡的字。輸入框裡打的內容，要用 .value 來讀，不是 textContent：

// 找到 id 是 "name-input" 的輸入框
const nameInput = document.getElementById("name-input");

// 讀出使用者打在輸入框裡的字（用 .value，不是 textContent）
const userName = nameInput.value;

讀出來的內容，一律是文字。就算使用者打的是數字，讀出來的也是文字，跟前面學過的「文字」一樣。

常見錯誤

讀輸入框時，如果寫成 textContent，讀到的會是空的，不是使用者打的字。要讀輸入框，一律用 .value。

下面的小網頁已經寫好了打招呼的程式。請動手試試：

  1. 在輸入框打上自己的名字，按「打招呼」，看畫面上出現什麼字。
  2. 什麼都不填，直接按一次，看看會變成什麼樣子。
  3. 把程式裡的「歡迎你」改成你想說的話，看預覽有沒有跟著變。

改完之後，右邊的預覽會自動更新。想回到原本的程式，按「重設」就可以。

這段程式分成三步來看：

  1. 讀取用 .value 讀出輸入框裡的字。
  2. 判斷用 if 檢查名字是不是空的。是空的，就執行 if 裡的提醒；不是空的，就執行 else 裡的問候。
  3. 顯示把結果寫進 message 的文字，同時改成對應的顏色。

用開發者工具的 Console 看紅字錯誤

程式寫錯的時候，瀏覽器不一定會跳出訊息告訴你。錯誤會寫在另一個地方，叫做 Console（主控台）。它是開發者工具裡的一個分頁。

以 Chrome 為例，打開的方法有兩種：

  • 在網頁上按右鍵，選「檢查」。
  • 直接按鍵盤：Windows 按 F12；Mac 按 ⌘ + ⌥ + J。

打開以後，切到上方的「Console」分頁。

程式出錯的時候，Console 會出現紅字。看到紅字，代表程式在那一行停下來了，後面的程式不會再執行。紅字旁邊會標出出錯的第幾行，例如：

script.js:3 Uncaught TypeError: Cannot read properties of null (reading 'textContent')

最前面的 script.js:3，意思是「script.js 的第 3 行」。看不懂後面英文的內容也沒有關係。先記住兩件事：看到紅字，就去看它標的第幾行；那一行附近，通常就是問題所在。更詳細的看法，第 7 章再說。

小提示

請自己把上面試試看的程式裡，一個引號（例如「請先輸入名字喔！」前後的其中一個引號）刪掉，再打開 Console，看看有沒有出現紅字。看完之後，記得改回來，或按「重設」。

跟 AI 一起做：看得懂、改得動

AI 寫的 JavaScript，常常比本章教的還多。這一章的目標不是讓你從零寫程式，而是看得懂大意，而且敢改。

請 AI 幫忙加上註解，是最好用的方法。例如：

對 AI 這樣說

這是我的 script.js（貼上檔案內容）。請在每一行上面加上中文註解，說明它在做什麼。只加註解，不要改程式的內容，也不要改名字。

加完註解以後，讀的時候可能會遇到下面幾種寫法。認得就好，不用全部會寫：

看到這幾種寫法

  • 看到 var：是舊的宣告寫法，意思和 let 差不多。本站一律用 let 和 const。
  • 看到 =>：是「箭頭函式」，也是寫函式的另一種寫法。本站一律用 function。
  • 看到用反引號 ` 包起來的文字，裡面有 ${ }：是把變數塞進文字裡的寫法。本站用 + 把文字接在一起。

和 AI 合作，還有三個習慣：

  1. 一次只改一件事。每次只請 AI 改一個地方，存檔、重新整理，確認沒問題，再進行下一步。
  2. 先備份。改之前，先把 script.js 複製一份，取名叫 script-backup.js。改壞了，把備份的內容貼回去就好。
  3. 看不懂就問。直接問 AI「這一行是在做什麼？」，不要照單全收。

✗ 這樣不好

「幫我把按鈕弄得更好玩」

範圍太大，AI 可能整段重寫，你也不知道它改了哪裡。

✓ 這樣比較好

「請在按下按鈕以後，把 greeting 的文字改成『晚安』。其他地方不要動。」

範圍小，改完容易檢查，出錯也容易找到原因。

常見錯誤

AI 有時會寫出本章沒教過的寫法。看不懂的地方，可以請它「換成比較簡單的寫法」，不要硬改。貼上去之前，記得先備份。

重點回顧

  • script 放在哪裡：用 <script src="script.js"></script> 接上程式，放在 </body> 前面，這樣程式執行時，網頁上的元素都已經出現了。
  • 變數：會變的用 let，不會變的用 const。名字用英文小駝峰。
  • 三種資料：文字要加引號，數字不用加，布林只有 true 和 false 兩種。
  • 陣列：一排有編號的收納盒，編號從 0 開始，用 length 可以數出有幾個。
  • if 判斷：條件成立做一件事，不成立做另一件事。比較「相等」要用 ===。
  • 函式：用 function 名字() { … } 把一組步驟包起來，需要時再呼叫。
  • 事件：用 addEventListener("click", 函式名字)，讓按鈕被按下的時候執行函式。傳進去的是函式的名字，後面不加括號。
  • 找元素、改內容：用 document.getElementById("id") 找到元素；用 textContent 改文字，用 style.屬性 改樣式，用 .value 讀輸入框。

動手做

在 my-first-web 裡，替自我介紹頁加上會動的問候語。

  1. 新增 script.js。在 my-first-web 資料夾裡（和 index.html 放在同一層），新增一個檔案，名稱是 script.js。
  2. 在 index.html 接上 script.js。在 </body> 前面加一行：<script src="script.js"></script>。
  3. 加上問候語和按鈕。在卡片裡，「我常用…」那段的下面、「留言給我」的標題上面，加入 <p id="greeting"> 和 <button type="button" id="greeting-btn">。按鈕要放在表單（form）外面。
  4. 寫出切換的程式。在 script.js 寫出：按一下按鈕，問候語就在「早安」和「午安」之間切換。提示：照前面「按一下切換問候語」的試試看，用一個布林變數記住現在是哪一句。可以自己寫，也可以請 AI 幫忙，但要它每一行加上註解。
  5. 測試。重新整理網頁，連按幾下按鈕，看問候語有沒有切換。如果沒反應，看下面的「按了沒反應？」。
  6. 加分題：夜間模式。在 index.html 再加一顆按鈕 id="night-btn"，同樣放在表單外面。在 script.js 寫出：按一下，整頁的背景（document.body）變成深色；再按一下，變回原本的淺灰色。卡片維持白色，像在暗暗的房間裡看一張亮亮的卡片。提示：document.body 就是整頁的 body，不用 getElementById 也找得到。

// 第 1 段：找到要用的元素（用 id 找）
const greeting = document.getElementById("greeting");
const greetingBtn = document.getElementById("greeting-btn");
const nightBtn = document.getElementById("night-btn");

// 第 2 段：記住現在的狀態
// isMorning 是 true 代表現在顯示「早安」，false 代表「午安」
let isMorning = true;
// isNight 是 false 代表一般模式，true 代表夜間模式
let isNight = false;

// 第 3 段：換問候語
function changeGreeting() {
    if (isMorning) {
        isMorning = false;
        greeting.textContent = "午安，王小明！";
    } else {
        isMorning = true;
        greeting.textContent = "早安，王小明！";
    }
}

// 第 4 段（加分題）：切換夜間模式，只換整頁的背景色
function toggleNight() {
    if (isNight) {
        isNight = false;
        document.body.style.backgroundColor = "#f3f4f6";
    } else {
        isNight = true;
        document.body.style.backgroundColor = "#111827";
    }
}

// 第 5 段：按鈕被按下的時候，執行對應的函式
greetingBtn.addEventListener("click", changeGreeting);
nightBtn.addEventListener("click", toggleNight);
按了沒反應？
  • script 放錯位置：程式要放在 </body> 前面。如果放在 head 裡，程式執行的時候，網頁上的元素還沒出現，就找不到它們。
  • id 拼錯：HTML 裡的 id，和 JavaScript 裡 getElementById("…") 的文字要一模一樣，包括大小寫和連字號。HTML 寫 greeting-btn，就不能寫成 greetingbtn。變數名字可以自己取，但括號裡的文字必須和 HTML 一致。
  • 用了全形符號：中文輸入法打出的 （ ）、「 」、；、＝，程式都不會動。要改成半形。
  • 忘了存檔，或瀏覽器沒重新整理：先按 Ctrl + S（Mac 是 ⌘ + S），再重新整理瀏覽器。
  • 看 Console 的紅字：打開 Console，看紅字標的是第幾行，回到那一行檢查。

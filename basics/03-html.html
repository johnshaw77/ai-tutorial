HTML：網頁的骨架

HTML 決定網頁上「有什麼」：標題、段落、清單、圖片、連結和表單。這一章把它們一個一個認識，並把你的自我介紹頁補得更完整。

閱讀 30 分練習 30 分

學完這篇，你會

  • 看懂標籤、巢狀和屬性，知道網頁骨架每一行在做什麼。
  • 會用標題、段落、清單、連結和圖片組出一頁內容。
  • 認得表單的基本零件，知道 label 為什麼要跟欄位連起來。
  • 請 AI 寫出 HTML 後，能自己找出每一塊用了哪個標籤。

標籤：替內容貼上名牌

第 2 章的 index.html 裡，到處都是像 <h1>、<p> 這樣的角括號。這些角括號包起來的文字，就叫做標籤（tag）。本章要把它們一個一個弄懂。

標籤通常成對出現，中間夾著內容。以一段最短的段落為例：

①

開始標籤

<p> 是開始的名牌，告訴瀏覽器「段落從這裡開始」。

②

內容

你好 是要顯示在畫面上的文字。

③

結束標籤

</p> 多了一條斜線，告訴瀏覽器「段落到這裡結束」。

把三個部分合在一起，就是一個元素（element）：<p>你好</p>。之後說「一個 p 元素」，指的就是這整組。

瀏覽器不會把角括號顯示在畫面上。它會讀取標籤，決定中間的內容「是什麼」：是標題、是段落，還是一張圖片。同樣的文字「你好」，放在 <h1> 裡會變成大標題，放在 <p> 裡就是一般的段落。

常見錯誤

最常見的錯誤，是忘了寫結束標籤，或是斜線方向寫反。例如把 </p> 寫成 <\p>，瀏覽器看不懂，後面的內容可能全部跑掉或變成奇怪的樣子。遇到畫面怪怪的，先檢查每個標籤有沒有成對、斜線有沒有寫對。

另外要知道，有些標籤沒有結束標籤，例如之後會學到的 <img>（放圖片）和 <br>（換行）。它們只需要一個標籤就能完成工作。現在先知道有這種情況就好，遇到時再說明。

巢狀：標籤裡面還有標籤

標籤可以放在別的標籤裡面，這叫做巢狀（nested）。可以把它想成便當盒的格子：大格子裡放小格子，小格子要整個待在大格子裡面，不能一半露在外面。

舉例來說，想讓一段文字中的「重要」兩個字變成粗體，要用 <strong> 標籤。strong 的意思是「粗體，表示重要」，下一節會再仔細介紹。它要放在 <p> 裡面。下面的對照可以看出差別：

✗ 這樣不好

<p><strong>重要</p></strong>

兩個元素交錯了：strong 還沒結束，p 就先結束。瀏覽器只能猜你的意思。

✓ 這樣比較好

<p><strong>重要</strong></p>

先開的後關。strong 完整地包在 p 裡面。

記住一個原則：後開的標籤要先關。就像穿衣服，最後穿上的外套要最先脫下來。

巢狀寫多了，很容易看不出誰包著誰。所以寫程式時會習慣用縮排（行首的空白）來排列。縮排不影響網頁的顯示，瀏覽器其實不在乎有沒有縮排。它的用途是讓人一眼就能看出：哪一行被包在哪一行裡面。

屬性：給標籤加上補充資料

有時候標籤本身還需要多一點資訊，例如「這個網頁是什麼語言」。這時候要把屬性（attribute）寫在開始標籤裡面。以第 2 章改過的第一行為例：

<html lang="zh-Hant-TW">

這一行裡，html 是標籤名稱，lang="zh-Hant-TW" 就是屬性。屬性的格式是：

  • 名稱="值"：先寫屬性名稱，接著等號，再接值。
  • 值要用雙引號包起來：寫成 "zh-Hant-TW"。少了引號或用了全形引號，瀏覽器可能會讀錯。
  • 可以有好幾個屬性：屬性之間用空白隔開，例如骨架裡的 <meta name="viewport" content="…"> 就有兩個屬性。

屬性是標籤的「補充說明」。標籤決定內容的種類，屬性則告訴瀏覽器更多細節，例如語言、連結要去哪裡、圖片從哪裡來。介紹連結和圖片時，會用到兩個很常見的屬性：href（連結要去哪裡），以及 src 和 alt（圖片從哪裡來、圖片的文字說明）。現在先認得「名稱="值"」這個格式就夠了。

註解：寫給人看的筆記

註解（comment）是寫給人看的筆記，瀏覽器會直接忽略它，不會顯示在畫面上。格式如下：

<!-- 這是註解 -->

註解有兩個常見用途：

  • 留筆記：提醒自己或同事這一段在做什麼，例如 <!-- 這裡放我的興趣 -->。
  • 暫時關掉一行：不想刪掉某一行，又想先看看沒有它會怎樣，就把它變成註解。

在 VS Code 裡，可以用快捷鍵快速加上或取消註解：Windows 按 Ctrl + /，Mac 按 ⌘ + /。先選取想註解的那一行，按一次加上，再按一次取消。

補充

AI 產生的程式碼常常有註解。如果看不懂某一段在做什麼，可以先看看上面有沒有註解；沒有的話，也可以請 AI 幫你每一段加上註解，再慢慢讀。

一行一行拆解網頁骨架

第 2 章結束時，我們用 VS Code 產生了一份網頁骨架。現在把它完整拆開來看。下面是 my-first-web/index.html 的內容：

<!DOCTYPE html>
<html lang="zh-Hant-TW">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>王小明的自我介紹</title>
</head>
<body>
    <h1>王小明</h1>
    <p>我是行政部的同事，很高興認識大家，請多指教！</p>
</body>
</html>

逐行說明如下：

  • <!DOCTYPE html>：告訴瀏覽器，這是現代的 HTML 網頁。它不是一般的標籤，只是一個宣告，寫在最前面就好。
  • <html lang="zh-Hant-TW">：整份網頁的最外層。lang 屬性表示這份網頁的語言是繁體中文（台灣）。
  • <head>：網頁的「頭部」，放的是給瀏覽器看的設定，本身不會直接顯示在畫面上。
  • <meta charset="UTF-8">：設定文字的編碼方式。第 1 章說過，網頁是文字檔，這一行就是告訴瀏覽器「用 UTF-8 的規則讀這些字」。少了它，中文可能會變成亂碼。
  • <meta name="viewport" ...>：讓網頁在手機上正常顯示的設定。我們目前只做電腦版，但它照抄就好，先不用深究。
  • <title>王小明的自我介紹</title>：瀏覽器分頁上顯示的名字。它不會出現在網頁的正文裡。
  • <body>：網頁的「身體」，所有看得見的內容都放在這裡面。

可以用兩張卡片來對照 head 和 body：

📋

head：給瀏覽器看的

像包裹上的寄件單。寫著編碼、分頁標題這些設定，收件的瀏覽器會先讀它，但它不是包裹裡的東西。

📦

body：給人看的

像包裹裡的東西。標題、段落、圖片，所有你在畫面上看到的內容，都放在這裡。

小提示

骨架每次都長得一樣，不用背。用 VS Code 輸入 ! 再按 Tab 就能產生，或請 AI 幫你產生。你只需要記得三件事：改 lang、改 title，以及把內容寫在 body 裡面。

試試看：觀察標籤的效果

下面的小網頁已經可以直接編輯。請試著做三件事，觀察右邊的預覽有什麼變化：

  1. 刪掉 </h1> 這個結束標籤，看看下面的段落會變成什麼樣子。看完再把它加回去。
  2. 把註解符號拿掉，也就是 <!-- 和 -->，看看那行文字會不會出現在畫面上。
  3. 改 <title> 的文字，例如改成「我的小網頁」，看看預覽有沒有變。你會發現預覽裡看不到它。這是因為 title 只會出現在瀏覽器的分頁上，不在網頁的正文裡。

標題與段落

網頁裡的文字，大多是標題和段落。HTML 用不同的標籤來區分它們。

標題有六個等級，從 h1 到 h6。數字越小越重要，就像書的目錄：

  • h1：書名。一個網頁通常只放一個。
  • h2：章的標題。
  • h3：節的標題，放在 h2 底下。

段落用 p，一段文字就放進一組 <p> 和 </p> 中間。

<h1>我的旅行日記</h1>
<h2>第一天</h2>
<p>今天我們到了京都。</p>
<p>晚上吃了很好吃的拉麵。</p>

這裡有一個常見的誤會。在 VS Code 裡按 Enter 換行，或打很多空白，瀏覽器都只會當成一個空白。所以要分段，就用新的 p。如果只想在段落裡面換行，才用 br。br 是「換行」，沒有結束標籤，直接寫一個就好：

<p>第一行文字<br>第二行文字</p>

想讓某段文字看起來更重要，可以用 strong。它預設會顯示成粗體：

<p>報名截止日是 <strong>11 月 5 日</strong>，請務必準時送出。</p>

✗ 這樣不好

為了讓字變大，就把每一行都包成 h1；或是一直用 br 把文字往下推，讓它看起來像段落。

✓ 這樣比較好

照「內容的重要程度」選標籤：章節用 h2，段落用 p，重要的字用 strong。字的大小和段落間距，之後交給 CSS 處理（第 4 章）。

清單：把幾件事列出來

很多時候，我們要把幾件事排成一排。HTML 有兩種清單：

  • ul：沒有順序的清單，前面是圓點。
  • ol：有順序的清單，前面是數字。

清單裡的每一項，都用 li（list item，清單項目）包起來。

例如「我的興趣」沒有先後順序，就用 ul：

<h2>我的興趣</h2>
<ul>
    <li>爬山</li>
    <li>看電影</li>
    <li>做咖啡</li>
</ul>

「泡咖啡的步驟」有先後順序，就用 ol：

<h2>泡咖啡的步驟</h2>
<ol>
    <li>把水煮到 90 度左右</li>
    <li>倒入咖啡粉，悶 30 秒</li>
    <li>慢慢注入熱水</li>
</ol>

常見錯誤

li 一定要放在 ul 或 ol 的裡面。如果直接把 li 放在頁面上，瀏覽器就不知道它是哪一份清單，排版會亂掉。

連結：點了會跳到別的地方

連結用 a 標籤（anchor，錨點）。格式是：

<a href="網址">顯示的文字</a>

href 是「要去哪裡」，標籤中間的文字是「讓人點的字」。例如：

<a href="https://zh.wikipedia.org/">維基百科</a>

連結有兩種寫法：

  • 連到別的網站：要寫完整網址，開頭是 https://。
  • 連到自己資料夾裡的另一個檔案：直接寫檔名就好，例如 about.html。這叫「相對路徑」，白話來說就是「從目前這個檔案出發，往旁邊找」。兩個檔案放在同一個資料夾，就不需要寫更多路徑。

常見錯誤

連到別的網站時，網址前面忘了寫 https://，瀏覽器會把它當成檔名，去自己的資料夾裡找，當然找不到。另外，連結文字要寫清楚。「看更多公司介紹」比「點這裡」好，因為看的人一眼就知道點下去會看到什麼。

連結還有一個選項 target="_blank"，可以讓連結在新的分頁開啟。這一章先不用，等你需要時再來用。

圖片：讓網頁有照片

圖片用 img 標籤。它是一個「不用結束標籤」的元素，一個標籤就能完成：

<img src="images/me.jpg" alt="王小明的大頭照">

這一行有兩個屬性：

  • src：圖片放在哪裡。這同樣是相對路徑，對應第 2 章資料夾裡的 images/ 資料夾。也就是說，圖片要先放進 images 資料夾，再寫 images/me.jpg。
  • alt：圖片的文字說明。圖片載入失敗時會顯示這段文字；看不見畫面的人，用螢幕報讀軟體時，它會把這段文字唸出來。所以要寫清楚圖片在呈現什麼。

常見錯誤

圖片沒出現，常見有三個原因：

  • 檔名大小寫不一樣。Me.JPG 和 me.jpg 在網頁上是不同的檔案。
  • 檔案沒有放進 images 資料夾，或資料夾名稱寫錯。
  • 副檔名其實是 .jpeg 或 .png，但程式碼寫成 .jpg。

小提示

手機拍的照片常常有好幾 MB，直接放上網頁會讓頁面變慢。放進去之前，可以先把它縮小一點：Windows 用「小畫家」的「調整大小」，Mac 用「預覽程式」的「工具」→「調整大小」。圖片要顯示多大，之後會用 CSS 來調整。

下面這個小網頁，用到了上面介紹的標題、段落、清單和連結（試試看裡沒辦法放圖片，圖片請在練習時用自己的檔案試）。建議你動手改一改：

  • 把 ul 改成 ol，看看圓點會不會變成數字。
  • 在清單裡新增一個 li，看看多了一行。

表單：讓別人填資料給你

你一定填過報名表、問卷，或是登入網站時要輸入帳號和密碼。這些需要「填寫」的畫面，在 HTML 裡都叫表單（form）。

表單由好幾個零件組成：文字框、單選鈕、下拉選單、送出按鈕。這一節我們先把每個零件認識一遍。之後的實戰範例〈部門聚餐報名表〉，就是用這些零件做出來的。

表單的零件一覽

📦

form 與 label

form 是整張表單的外框。label 是欄位的名稱，例如「姓名」。

✏️

input

輸入框。用 type 屬性換種類：文字、Email、數字、單選鈕。

🔽

select、textarea、button

select 是下拉選單，textarea 是多行文字，button 是按鈕。

form：整張表單的外框

form 把所有欄位包在一起。表單裡的欄位，都要放在 <form> 和 </form> 中間：

<form>
    <!-- 姓名、Email、送出按鈕…都放在這裡面 -->
</form>

label：欄位的名稱

label 是欄位旁邊的文字，告訴填寫的人這格要寫什麼。它的內容就是你平常看到的字：

<label for="name">姓名</label>

for 屬性很重要，下一段會再說明。

input：輸入框，用 type 換種類

input 是真正讓人輸入的地方。它的種類由 type 屬性決定：

  • type="text"：一般文字，例如姓名。
  • type="email"：Email。瀏覽器會檢查有沒有 @ 符號。
  • type="number"：數字，例如人數。
  • type="radio"：單選鈕，圓圈形狀，一次只能選一個。
<input type="text">
<input type="email">
<input type="number">

input 是沒有結束標籤的元素，像 img 和 br 一樣，寫一個標籤就好，不用再寫 </input>。

select 與 option：下拉選單

要讓人從幾個選項裡挑一個，用下拉選單。select 是選單本身，每個選項用 option 來寫：

<select>
    <option>行銷</option>
    <option>業務</option>
    <option>研發</option>
</select>

textarea：多行文字

留言、備註通常會寫好幾行，要用 textarea。它跟 input 不同，要有結束標籤：

<textarea></textarea>

button：送出按鈕

按鈕的文字寫在標籤中間：

<button type="submit">送出</button>

label 的 for 要和 input 的 id 一樣

這是表單最重要的一個觀念。在 input 上加一個 id，再到 label 的 for 寫一模一樣的名字，兩者就連起來了：

<label for="email">Email</label>
<input type="email" id="email">

連起來之後有兩個好處：

  • 點文字也能選到欄位。點「Email」這兩個字，游標會直接跳進輸入框，不用精準地點小格子。
  • 螢幕報讀軟體知道這格是什麼。看不見畫面的人，聽到的會是「Email，編輯區」，而不是只聽到一個空白的格子。

✗ 這樣不好

<p>Email</p>

<input type="email">

文字和輸入框是兩個獨立的東西。點「Email」沒有反應，報讀軟體也不知道這格是什麼。

✓ 這樣比較好

<label for="email">Email</label>

<input type="email" id="email">

用 for 和 id 連起來，點文字就能選到欄位，報讀軟體也知道這格是什麼。

radio：單選鈕要用同一個 name

單選鈕的特色是「多選一」，例如葷食或素食只能選一種。要讓瀏覽器知道這幾個圓圈是同一組，它們必須有相同的 name：

<label><input type="radio" name="diet"> 葷</label>
<label><input type="radio" name="diet"> 素</label>

常見錯誤

如果兩個單選鈕的 name 不一樣，它們就變成各自獨立的圓圈，可以同時都選。看到這種情況，先檢查 name 是不是寫一樣。

required 與 placeholder

輸入框還有兩個常用的屬性：

  • required：必填。沒填就按送出，瀏覽器會跳出提醒，表單不會送出。寫上這個字就好，不需要寫值。
  • placeholder：輸入框裡的灰色提示字，例如「請輸入 Email」。它只是提示，輸入後就會消失。

常見錯誤

不能用 placeholder 取代 label。填寫的人一開始輸入，提示字就不見了，忘記這格是什麼。欄位的名稱一定要用 label 寫出來。

補充

現在按下表單的「送出」，頁面只會重新載入一次（網址後面可能多出一串你填的文字），資料不會傳到任何地方。要讓表單真的做事，例如把資料存起來、顯示「報名成功」，需要學 JavaScript。第 5 章學完後，我們會在實戰範例裡處理。

試試看：做一張小表單

下面是一張「部門聚餐調查」的表單。試著點一下「姓名」兩個字，看游標會不會跳進輸入框；再點「葷」和「素」，確認一次只能選一個。也可以把其中一個單選鈕的 name 改掉，看看會發生什麼事。

在預覽區按「送出」不會有任何反應，也看不到「必填」的提醒。這是預覽區的安全限制，不是你寫錯了。想看 required 的效果，可以在練習時用自己的檔案試：不填姓名就按送出，瀏覽器會跳出提醒。

跟 AI 一起做：請 AI 產生頁面，再自己認標籤

跟 AI 一起做

AI 幾秒鐘就能寫出一頁 HTML。但你要看得懂它寫了什麼，才知道對不對、要怎麼改。建議的方法是三步：

  1. 請 AI 產生。把需求說清楚，讓 AI 寫出 HTML。
  2. 存成檔案，用 Live Server 打開。在 my-first-web 裡新增一個檔案，例如 ai-test.html，把內容貼進去。不要直接貼進 index.html，免得蓋掉你自己寫的內容。
  3. 用開發者工具「檢查」。在畫面上的每一塊按右鍵，選「檢查」，對照 Elements 裡的那一行，看它是哪個標籤。

下面是一段可以直接複製的提示詞，請 AI 幫你做一個自我介紹網頁：

對 AI 這樣說

請幫我寫一個自我介紹網頁，只用 HTML，不要 CSS 和 JavaScript。內容要有：我的名字當大標題、一段自我介紹、一個「我的興趣」清單（3 項）、一張照片（檔案在 images/me.jpg）、一個連到公司網站的連結。請在每個區塊上面加中文註解，說明用了什麼標籤、為什麼。

提示詞寫法不同，AI 給的結果也不一樣：

✗ 這樣不好

「幫我做一個網頁」

範圍太大，AI 可能會加上一堆 CSS 和 JavaScript，還有你還沒學過的標籤，看不懂也不知道要不要留下。

✓ 這樣比較好

說清楚三件事：只要 HTML、要哪些內容、要中文註解。

範圍清楚，結果就容易檢查，也容易對照本章學過的標籤。

常見錯誤

AI 有時候會塞進你沒要的 CSS 或 JavaScript，或用你還沒學過的標籤。遇到看不懂的地方，直接問它「這一行是什麼意思」，或「這個標籤可以不用嗎」。不要整段照貼，貼上去之前，先確認每一行你都能解釋。

重點回顧

  • 標籤與巢狀：網頁是由標籤一層包一層組成的。標籤要成對，裡面的標籤要在外面的標籤裡面關好。
  • 屬性：在開始標籤裡加的設定，例如 href、src、alt、type。
  • 骨架：head 放看不見的設定（例如標題、編碼），body 放畫面上看得見的內容。
  • 常用標籤：標題 h1–h3、段落 p、清單 ul/ol/li、連結 a、圖片 img。
  • 表單：label 的 for 要和 input 的 id 一樣，才能把文字和欄位連起來。
  • 請 AI 寫完，要自己看懂：一行一行對照，看不懂的地方就問，不要整段照貼。

動手做

把第 2 章做的自我介紹頁，擴充成一個完整的內容頁。

  1. 建立 images 資料夾，放照片。在 my-first-web 裡新增一個資料夾，名稱是 images。放一張你自己的照片，或任何你喜歡的圖片，並改名為 me.jpg。如果你的檔案是 png，就改名為 me.png，下一步的 src 也要跟著改。
  2. 在 h1 下面加一張圖片。用 img 標籤，src 寫 images/me.jpg，並記得加上 alt 屬性，寫一段圖片的文字說明。
  3. 加「我的興趣」清單。新增一個 h2，文字是「我的興趣」。下面接一個 ul，裡面至少放 3 個 li。
  4. 加「工作上的我」段落。新增一個 h2，文字是「工作上的我」。下面寫一段 p，並用 strong 標出一個重點。
  5. 加一個連結。用 a 標籤，連到公司網站或你常用的網站。記得 href 要寫完整的網址，開頭是 https://。
  6. 存檔，看結果。按 Ctrl + S（Mac 是 ⌘ + S），用 Live Server 看畫面。打開開發者工具的 Elements 面板，找到你剛加的 img、ul 和 a，確認它們都在。
  7. 加分題：留一張表單。在最下面加一個 h2，文字是「留言給我」。下面做一張小表單，有姓名（input）、留言（textarea）和送出按鈕（button）。每個輸入框都要用 label 和 for、id 連起來。最後幫姓名加上 required，存檔後不填姓名按送出，看看瀏覽器的提醒。

圖片沒出現，或版面怪怪的？
  • 圖片檔名或副檔名不符：先確認副檔名有顯示出來。Windows 在檔案總管的「檢視」→「顯示」勾選「副檔名」；Mac 在 Finder 的「設定」→「進階」勾選「顯示所有檔案副檔名」。檔案其實是 me.jpg.png 或 me.png，但程式碼寫的是 me.jpg，就會找不到。
  • 圖片不在 images 資料夾：圖片要放在 my-first-web/images/ 裡面，src 寫 images/me.jpg，資料夾名稱和檔名都要一樣。
  • 標籤忘了結束：某個標籤沒有關上，後面的內容就全部變成標題或粗體。用 VS Code 檢查，每個開始標籤都要有對應的結束標籤，例如 <h2> 要有 </h2>。
  • 中文變成亂碼：確認檔案開頭的 head 裡有 <meta charset="UTF-8">，而且 VS Code 右下角的編碼是 UTF-8。

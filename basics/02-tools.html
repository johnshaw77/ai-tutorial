瀏覽器：用 Chrome 看你的網頁

瀏覽器就是你平常用來「看網頁」的程式，例如 Chrome、Edge、Safari。上一章說過，瀏覽器會把網頁檔案畫成你看到的畫面。

本課建議統一用 Chrome。原因很簡單：教學裡的步驟和按鈕名稱都是照 Chrome 寫的，你用同一個，跟著做時畫面才會一樣，比較不會迷路。

Edge 也可以。Edge 和 Chrome 的核心相同，操作幾乎一樣，只是外觀不同。

小提示

公司電腦如果不能自行安裝軟體，直接用 Edge 就好。本課的步驟在 Edge 上也能照做。

開發者工具：網頁的透視鏡

你有沒有想過，一個網頁到底是怎麼排出來的？瀏覽器裡藏了一個工具，可以把網頁的引擎蓋打開，看裡面的零件，這就是開發者工具。

它像汽車的引擎蓋，或醫院的 X 光：不用改任何東西，就能看到網頁底下的 HTML（骨架）和 CSS（外觀）。而且，你可以打開任何一個網頁來看，不限於自己做的。

怎麼打開？

有兩種方法，任選一種：

  • 用滑鼠：在網頁上按右鍵，選「檢查」。
  • 用快捷鍵：Windows 按 F12，或按 Ctrl+Shift+I；Mac 按 ⌥ Option+⌘ Command+I。

打開後，畫面的一側或下方會出現一塊面板。上面有很多分頁，我們先認識最常用的兩個。

🔍

Elements（元素）

看網頁的 HTML 結構。滑鼠移到某一行，畫面上對應的地方會亮起來。右邊還會看到這個元素的 CSS 樣式。

🚨

Console（主控台）

看錯誤訊息。出錯時會出現紅字，紅字就是網頁在告訴你哪裡壞了。第 7 章會再細講。

這裡只先介紹這兩個，因為它們是新手最常用的。其他分頁等需要時再說。

動手試一試：改一下新聞標題

這個小實驗只要四步，你會發現原來網頁是可以「改」的。

  1. 打開新聞網站隨便挑一個新聞網站，例如你平常會看的入口網站。
  2. 檢查標題在任一則新聞標題上按右鍵，選「檢查」。
  3. 雙擊改字在 Elements 面板裡，雙擊標題那行的文字，改成你自己的名字。
  4. 按 Enter 看變化按下 Enter，回頭看網頁，標題已經變成你的名字了。

補充

這只改了你自己電腦上的畫面，別人看不到，也不會真的改到那個新聞網站。重新整理頁面（按 F5），畫面就會恢復原樣。所以不用怕弄壞。

常見錯誤

不要把你在 Console 裡貼上陌生人給的程式碼。有些人會用這招騙走帳號。這門課只會叫你貼課程裡提供的內容，其他一律不要貼。

VS Code：寫網頁的筆記本

上一章我們用記事本就能寫網頁。但記事本只是純文字，不會幫你上色，也不會提醒你少打了一個符號。

所以工程師通常會用專門的編輯器。這一課我們用的是 VS Code（全名 Visual Studio Code）。它有三個好處：

  • 會上色：標籤、文字、符號都用不同顏色標示，一眼就看得出結構。
  • 會自動補完：打到一半會跳出建議，少打字，也少出錯。
  • 可以看整個資料夾：一個網站有好幾個檔案，全部列在左邊，不用一個一個找。

VS Code 是微軟出品，免費，很多工程師每天都在用。

安裝步驟

  1. 打開官網：https://code.visualstudio.com/，點下載按鈕。
  2. Windows 使用者：選 User Installer。這個版本通常不需要系統管理員權限。安裝過程中，建議勾選「加入到檔案總管的右鍵選單（以 Code 開啟）」，之後在資料夾上按右鍵就能快速打開。
  3. Mac 使用者：下載後，把 Visual Studio Code 拖進「應用程式」資料夾。
  4. 打開看看：看到歡迎畫面，就代表安裝成功了。

常見錯誤

公司電腦如果被擋、或安裝時跳出權限要求，請先找 IT 同仁協助。不要自己去找來路不明的安裝檔，以免電腦出問題。

認識 VS Code 的畫面

第一次打開會覺得畫面很多。先認識下面四個區域就夠了：

  • 左邊最窄的一條：活動列。上面是一排圖示。點像文件的圖示，可以打開「檔案總管」；下一節會用到的「擴充功能」，圖示是四個方塊。
  • 活動列旁邊：側邊欄。顯示你目前資料夾裡有哪些檔案，跟在檔案總管看到的一樣。
  • 中間最大的區域：編輯區。你寫程式的地方。可以同時開好幾個檔案，每個檔案會變成上方的一個分頁，點分頁就能切換。
  • 最下面一條：狀態列。顯示目前檔案的一些資訊，例如右下角會寫著使用的語言。

三個讓新手輕鬆很多的設定

裝好以後，先做下面三個設定，之後會省下很多麻煩。

安裝擴充功能的共同步驟

VS Code 的「擴充功能」就像手機上的 App，可以加上新的功能。下面 (a)、(c) 會用到，安裝方法都一樣：

  1. 點擴充功能圖示左邊活動列上，四個小方塊的圖示。
  2. 搜尋名稱在上方搜尋框輸入要裝的名稱。
  3. 確認作者看清楚作者是不是正確的那一位。
  4. 按安裝等它裝完，依提示重新啟動 VS Code。

也可以用快捷鍵直接打開擴充功能：Windows 按 Ctrl+Shift+X，Mac 按 ⌘+Shift+X。

常見錯誤

同名的擴充功能很多，有些是假冒的。請認明下載數多、作者正確的那一個，再按安裝。

(a) 把介面換成中文

預設是英文畫面。依照上面的步驟，搜尋 Chinese (Traditional) Language Pack，作者是 Microsoft，按安裝，然後重新啟動。重新打開後，選單和按鈕就會變成中文。

(b) 打開自動儲存

在選單列點「檔案」，勾選「自動儲存」。勾選後，VS Code 會自動幫你存檔。

小提示

新手最常遇到的問題是「我改了，怎麼畫面沒變？」，多半是忘記存檔。檔案沒存，瀏覽器看到的還是舊的內容。打開自動儲存，改完字停一下就會自動存，比較不會卡住。

(c) 安裝 Live Server

Live Server 是一個「即時預覽」的工具，作者是 Ritwick Dey。依照上面的步驟，搜尋 Live Server 並安裝。裝好以後：

  1. 在 HTML 檔案上按右鍵，選「Open with Live Server」。
  2. 瀏覽器會自動打開網頁。
  3. 之後每次存檔，畫面都會自動更新，不用自己按重新整理。

瀏覽器網址列會出現類似 http://127.0.0.1:5500/index.html 的網址。這是「只有你的電腦看得到」的位址，別人打不開，可以放心練習。

補充

不裝 Live Server 也可以。直接雙擊 HTML 檔，用瀏覽器打開就好。差別是每次改完存檔，都要自己在瀏覽器按 F5（Mac 是 ⌘+R）重新整理。

整理資料夾的好習慣

寫網頁會產生很多檔案。從一開始就把它們放在同一個地方，之後才找得到。本課的所有作品，都請放在同一個資料夾裡，例如桌面上的 my-first-web。

檔名也有幾個小規則：

  • 全部用英文小寫。
  • 不要有空白，也不要用中文。
  • 單字之間用連字號 - 連起來，不要用底線或空白。

✗ 這樣不好

我的 網頁(最終版).HTML

✓ 這樣比較好

about-me.html

為什麼要這麼講究？因為網頁放上網路後，中文和空白在網址裡會變成一串像 %E6%88%91... 的亂碼，連結很容易壞掉。另外，Index.HTML 和 index.html 在網路上會被當成兩個不同的檔案，大小寫一不小心就出錯。

首頁的檔名一定要叫 index.html。它就像網站的大門，瀏覽器打開一個網站時，預設就是找這個檔案。

整門課做完時，你的資料夾大致會長這樣（之後的章節會慢慢加入 style.css 和 images/）：

my-first-web/
        ├── index.html      ← 首頁（網站的大門）
        ├── style.css       ← 之後會加入
        └── images/         ← 之後會加入（放圖片）

用 VS Code 打開資料夾，寫第一個檔案

我們已經在本章前面裝好 VS Code。接下來用它打開剛剛建立的資料夾，並建立第一個檔案。

  1. 打開 VS Code，點選上方選單的「檔案」→「開啟資料夾」，選擇桌面上的 my-first-web，按「開啟」。
  2. 在左邊的「檔案總管」（就是最上面那個像文件的圖示）中，點選空白處的「新增檔案」圖示，輸入 index.html，按 Enter。
  3. 點開 index.html，在空白的檔案裡輸入一個驚嘆號 !，再按 Tab（或 Enter）。VS Code 會自動幫你產生一份網頁的骨架。
  4. 把 <html lang="en"> 那一行的 lang="en" 改成 lang="zh-Hant-TW"，這樣瀏覽器就知道這是繁體中文的網頁。
  5. 把 <title> 裡的 Document 換成網頁標題（會顯示在瀏覽器分頁上），再到 <body> 和 </body> 中間寫要顯示在畫面上的內容。

VS Code 產生出來的內容長這樣：

<!DOCTYPE html>
        <html lang="en">
        <head>
            <meta charset="UTF-8">
            <meta name="viewport" content="width=device-width, initial-scale=1.0">
            <title>Document</title>
        </head>
        <body>

        </body>
        </html>

小提示

這份骨架看不懂沒關係，大部分人第一次看都會覺得一頭霧水。第 3 章會一行一行拆開來解釋，現在只要知道：這是網頁的標準起點，每個網頁都長得差不多。

跟 AI 一起做：卡關時怎麼問

跟 AI 一起做

安裝工具和設定環境，是新手最容易卡住的地方。畫面和選單常常因為版本或電腦不同而不一樣，看文章找不到對應的步驟很正常。這時候 AI 很適合幫你排除問題。

好的提問要包含四件事：

  • 作業系統：Windows 11，還是 macOS。
  • 你在做哪一步：例如「在 VS Code 安裝 Live Server」。
  • 畫面上出現的完整訊息：可以直接截圖貼給 AI。截圖前先看一下，畫面上不要有公司機密或同事的個人資料。
  • 你已經試過什麼：免得 AI 叫你做一樣的事。

下面是一個好的提問範例，你可以照著改成自己的情況：

對 AI 這樣說

我用 Windows 11，在 VS Code 安裝 Live Server 後，對 index.html 按右鍵沒有出現 Open with Live Server。我已經重新啟動過 VS Code。請一步一步告訴我可能的原因和檢查方法，用新手聽得懂的話。

再比較一個不太好的問法：

✗ 這樣不好

「Live Server 不能用怎麼辦」

✓ 這樣比較好

「我用 Windows 11，對 index.html 按右鍵沒有 Open with Live Server，我已經重新啟動 VS Code。請一步一步告訴我可能原因。」

重點回顧

  • 用 Chrome 和開發者工具看網頁，用 VS Code 寫網頁，兩者都要先裝好並完成設定（Live Server 等三個設定）。
  • 作品統一放在同一個資料夾（例如 my-first-web），檔名用英文小寫加連字號，首頁一定叫 index.html。
  • 在 VS Code 空白檔案輸入 ! 再按 Tab，就能產生網頁骨架，記得把 lang 改成 zh-Hant-TW。
  • 卡關時請 AI 幫忙，問題要寫清楚作業系統、步驟、完整訊息和你試過的做法。

動手做

我們要開始做你的第一個作品：我的自我介紹頁。之後每一章都會把它再擴充一點。

  1. 在桌面建立資料夾。在桌面按右鍵，選「新增」→「資料夾」（Mac 是「新增資料夾」），名稱輸入 my-first-web。
  2. 用 VS Code 打開它，新增 index.html。在 VS Code 選「檔案」→「開啟資料夾」，選 my-first-web。接著在檔案總管點「新增檔案」，輸入 index.html。
  3. 產生骨架，改語言與標題。在檔案裡輸入 ! 再按 Tab。把 lang 改成 zh-Hant-TW，<title> 改成「王小明的自我介紹」（請換成你自己的名字）。
  4. 寫上你的名字和一句介紹。在 <body> 裡面，加一行 <h1> 寫你的名字，再加一行 <p> 寫一句自我介紹。
  5. 打開看看。存檔（Windows 按 Ctrl + S，Mac 按 ⌘ + S）。在 VS Code 對 index.html 按右鍵，選「Open with Live Server」；如果沒有這個選項，就直接在檔案上雙擊。確認畫面上出現你的名字和介紹。
  6. 加分題：用開發者工具看看標題。在網頁上你的標題文字按右鍵，選「檢查」，在 Elements 面板找到對應的那一行，看看它在 HTML 裡長什麼樣子。
參考答案 
<!DOCTYPE html>
      <html lang="zh-Hant-TW">
      <head>
          <meta charset="UTF-8">
          <meta name="viewport" content="width=device-width, initial-scale=1.0">
          <title>王小明的自我介紹</title>
      </head>
      <body>
          <h1>王小明</h1>
          <p>我是行政部的同事，很高興認識大家，請多指教！</p>
      </body>
      </html>
畫面沒出現？
  • 檔名不對：檔案可能變成 index.html.txt，或大小寫寫成 Index.HTML。請確認檔名是全部小寫的 index.html。
  • 忘了存檔：VS Code 標題的檔名旁如果有圓點，代表還沒存檔。按 Ctrl + S（Mac 是 ⌘ + S）再重新整理瀏覽器。
  • 沒有「Open with Live Server」選項：可能是 Live Server 還沒裝好。這時候直接在 index.html 上雙擊，用瀏覽器打開也可以，只是畫面不會自動更新。
